# Chrome Zoom Level Presetter

Chromeの拡大率（ズームレベル）をプリセットから1クリックで切り替える拡張機能です。
モニターの変更時などに、すべてのページの拡大率を一括で変更するのに便利です。

## 特徴

- **1クリック切り替え**: 80%, 100%, 125%, 150%, 200% のプリセットから選択。
- **全タブ適用**: 現在開いているすべてのタブに即座に反映。
- **自動永続化**: 新しく開くタブにも設定したズームレベルを自動適用。
- **自動バージョンアップ**: GitHub Actionsにより、mainブランチへのプッシュで自動的にバージョンが更新されます。

## 開発とビルド

### 必要条件
- Node.js (v20以上推奨)
- npm

### インストール
```bash
npm install
```

### ビルド
```bash
npm run build
```
ビルド完了後、`dist` ディレクトリが生成されます。

### Chromeへのインストール
1. Chromeで `chrome://extensions/` を開きます。
2. 右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、本プロジェクトの `dist` フォルダを選択します。

## 自動リリース
GitHubにプッシュすると、GitHub Actionsが自動的に以下の処理を行います。
1. バージョンの自動インクリメント（patch）。
2. `dist` フォルダのビルド。
3. リリース用ZIPファイルの作成とGitHub Releaseへのアップロード。
